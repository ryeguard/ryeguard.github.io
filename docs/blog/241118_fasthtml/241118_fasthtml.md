# Deploying a FastHTML app

1. https://vercel.com/templates/python/fasthtml-python-boilerplate
2. Click deploy, create the project repo in Github and wait for the deployment to finish.
3. Optional: Add CNAME to your domain registrar. Then, add the domain to the Vercel project settings. In my case, I added `chat.rygard.se`.
4. Clone your project repo to your local machine.
5. Start developing!
